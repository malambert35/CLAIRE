# Using the memory workspace

Open Family Memories / Souvenirs de famille and choose New memory / Nouveau souvenir.
Enter a title, your testimony, optional event date and source. Event dates accept YYYY,
YYYY-MM or YYYY-MM-DD. Choose personal recollection, verified evidence, uncertain
information or AI interpretation; CLAIRE does not infer verification on your behalf.

Visibility defaults to Only me. My family shares the current version with current
household members. Review the form and tick the confirmation before saving. A success
message appears only after the archive and catalogue have committed.

The owner can edit, inspect previous revisions, move a memory to deleted, and restore
it. Every change creates a revision; the original wording stays in the archive.
Deleted memories are visible only to the owner. Restoring also restores their previous
visibility and requires confirmation. Sharing a current version never shares its history.
Family administrators cannot read another member's private memories or edit their stories.

Search currently matches titles, not semantic content. Family Timeline orders permitted
memories by the supplied event date, across pages; undated memories come last. No graph
or AI inference is involved. Source references are retained as testimony, not fetched as
external URLs. Embedded remote Markdown images are not loaded.

Accounts with the reader role can read permitted content but cannot create or change it.
Explicit per-person sharing and ownership transfer are not available yet.

An archive/catalogue discrepancy returns 503 instead of returning potentially stale
private data. Follow docs/recovery.md to reconcile offline. Do not delete source files
to fix an application error.
